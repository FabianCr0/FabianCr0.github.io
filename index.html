Introduction

Before I get started on the evolution of HTML, I need to introduce you to the man who started it all, his name was Tim Berners-Lee, he was an English computer scientist who worked at CERN (The European Organization for Nuclear Research) at the time he made propositions on creating the World Wide Web. He was only 35 years old when he invented HTML (Hypertext Markup Language) in 1990. He created the World Wide Web at first so scientists could share research documents more easily with each other. He thought of this to combine all technologies of hypertext and computers into one system.

History of HTML

  • HTML 2.0

    • HTML 2.0 was published in 1995, and it became the first version of HTML to become necessary for building websites. It added just a few new tags and wasn’t that much different to 1.0, but these new tags really played a part in forming the growing web. It also added style sheets so developers could customize their page as they liked.

  • HTML 3.2

    • HTML 3.2 launched in 1997 after its endorsement by big tech companies such as Microsoft, IBM, and Netscape. This version took on Netscape’s visual markup tags which got rid of extensions and math formulas completely. Marquee text played a big time in this version because it lets designers make their designs using less code. A big improvement came for style sheets too.

  • HTML 4.01

    • HTML 4.01 came with a big change to the internationalization of documents so many people who spoke different languages can learn how to build their own websites. It also came with some minor bug fixes and support for more scripting languages and media options. This then became the new standard for a while; it launched in 1999.

  • HTML 5.1

    • HTML 5.1 was the last major version; it was released in 2014. It has added a lot more new features that make the web what it is today. This includes a big change that allowed SQL databases and an application cache that let offline data be stored on the user's machine. It also added two new media tags which made displaying video or playing audio a lot easier and better management of how CSS and JavaScript interacted with it.

History of CSS

  • CSS 1.0

    • CSS 1.0 is the most basic version of CSS; it was introduced in 1996 to help design and styling websites easier. It allowed you to change the background and color, let you control test alignment, change the font, and more.

  • CSS 2.0

    • CSS 2.0 only brought a few new features such as being able to control the aspect of different Media Types, adding new Style options and Element Positioning. It was released in 1998.

  • CSS 2.1

    • CSS 2.1 was a pretty important update as it fixed a lot of bugs that were present in CSS 2.0. Not much else happened to it.

  • CSS 3.0

    • Now CSS 3.0 is where it majorly changed how websites are designed today. It was introduced as separate different modules which each play a big role in web design. Some of the most interesting modules include Variables which make styling and customization so much easier to do, Animations which really added new life to websites, better support for smaller screens and devices like phones or tablets, The Grid Layout which brought two-dimensional control, and overall improved everything else in the past versions.
